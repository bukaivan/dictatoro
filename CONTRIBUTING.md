# Contributing

Bug reports, translations, usability feedback and focused fixes are welcome.
Include the app and Windows versions, model/language, reproduction steps, expected
behavior and actual behavior. Review logs before posting: remove personal text,
audio, credentials and local account paths.

For recognition issues, describe the microphone and noise conditions. Publish a sample
only if you own it or have permission, and state its license. Benchmark results need
dataset details, scoring rules and limitations.

Follow BUILDING.md, run relevant tests and describe verification. Keep dependency
notices and source-access instructions intact. Application-code contributions are
submitted under this repository's MIT license.
