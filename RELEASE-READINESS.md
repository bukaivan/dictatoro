# Проверка перед выпуском — 25 сентября 2026

Статус: стабильный выпуск заблокирован. Публикация на GitHub не выполнялась.
Подписанного установщика пока нет. Эта проверка не является юридическим заключением.

## Выполнено локально

- Проверены контрольные суммы Python и 30 wheel-пакетов по зафиксированным данным
  издателей. Все 129 поставляемых нативных файлов среды совпали с файлами этих архивов.
  Отдельно устанавливаемый Intel OpenMP в число поставляемых файлов не включён.
- Исходные файлы LICENSE/LICENCE/NOTICE из этих архивов сохранены без изменений.
  Для пакетов без отдельного текста в wheel проверено наличие дополнительных уведомлений.
- Проверены исходные архивы Qt/PySide, версии зависимостей и хеши встроенной Base.
- Дополнены уведомления подмодулей CTranslate2 по точным upstream-коммитам.
- Собраны уведомления из 535 пакетов Cargo.lock официальных исходников tokenizers
  и hf-xet. Это расширенный список с тестовыми/необязательными зависимостями и другими
  платформами, а не утверждение о наличии всех 535 пакетов в Windows-бинарнике.
  Архивы сверены с хешами в lock-файлах. Для MPL/CDDL-пакетов из списка добавлены исходники.
- Пройдены шесть сценариев автоматических тестов приложения и ещё два прогона
  интерфейса с масштабированием 150% и 200%.
- Две независимо подготовленные среды совпадают по 2930 файлам.
- Проверен настоящий переход с установленной Qt 6.8.3 на текущую сборку:
  установка, обновление, запуск с внешним Intel OpenMP, Base без сети и удаление.
  Пользовательский посторонний файл при удалении сохранён.

Предыдущие отчёты ошибочно отмечали повторную установку одной версии как переход
с Qt 6.8.3. Эта отметка исправлена; новая проверка сначала устанавливает старый
пакет и проверяет фактическую версию Qt. Intel/Microsoft vendor-установщики в
автоматическом тесте не запускаются; обнаружение Intel подменено для изоляции.

## Что ещё не закрыто

1. **Подпись и Smart App Control.** На другом ПК подтверждена блокировка unins000.exe.
   SIGNEDRELEASE и проверка подписей подготовлены, сертификат/провайдер не подключён.
   Нужен настоящий подписанный пакет и тест обновления/удаления при включённой защите.
   Не отключать защиту ради тестового приложения.
2. **Полный состав нативных библиотек.** Хеш wheel доказывает происхождение файла,
   но не перечисляет всё, что в него статически встроено. Windows-рецепт CTranslate2
   4.8.2 включает MKL 2025.3, oneDNN 3.1.1 и GPU-поддержку CUDA 12.8.1.
   CPU-режим приложения и отсутствие отдельной cuDNN DLL не исключают встроенный
   код CUDA. Требуется проверить соответствующие условия распространения либо
   подготовить и испытать собственную CPU-сборку без этой зависимости.
3. **Точность Rust-инвентаря.** Сохранён широкий набор уведомлений по исходным lock-файлам.
   Точные параметры сборки publisher wheels ещё не сопоставлены с этим набором.
   Для шести записей расширенного списка нет подтверждённых отдельных текстов:
   r-efi 5.3.0/6.0.0, rustls-platform-verifier-android 0.1.1, symbolic-common 12.17.3,
   winapi-i686-pc-windows-gnu 0.4.0 и winapi-x86_64-pc-windows-gnu 0.4.0.
   Сначала определить участие этих optional/target-specific компонентов в Windows
   x64 MSVC-сборке; не считать их автоматически используемыми только из-за Cargo.lock.
4. **Реальный чистый Windows.** Нужны результаты установки Intel/Microsoft, отмены,
   возможной перезагрузки, автозапуска, ярлыков, выбранной папки и удаления в реальной
   системе. Успех изолированного теста на компьютере разработчика этого не доказывает.
5. **Практическая работа.** Проверить клавишу/кнопку мыши, вставку в Chrome и Блокнот,
   перевод, переключение моделей и работу после перезагрузки на другом ПК.

## Порядок дальнейших действий

Сначала закрыть состав/условия нативных компонентов. Затем выбрать подпись.
Бесплатный SignPath требует публичный открытый проект и проверку соответствия;
проприетарные вложения Intel/CUDA не следует автоматически считать допустимыми.
Для подписи до публикации нужен другой подходящий провайдер и проверка личности.
Никакая платная услуга этой работой не заказана.

После получения подписи собрать итоговый пакет, проверить три подписи (установщик,
приложение, установленный деинсталлятор), обновить старую версию на отдельном ПК и
удалить её через Windows Settings при включённом Smart App Control. До этого не
обозначать выпуск как стабильный и не обещать отсутствие предупреждений Windows.
